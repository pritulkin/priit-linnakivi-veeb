# Priit Linnakivi — portfoolio

Staatiline, eesti keeles portfoolio. Kasutab ainult HTML-i, CSS-i ja brauseri JavaScripti; build-tööriista ega backend'i pole.

## Käivitamine

Serveeri projekti juurkaust staatilise failiserveriga. Näiteks:

```sh
python -m http.server 8000
```

Seejärel ava `http://localhost:8000`. Veebilehe saab avaldada ka mis tahes staatilise hostimise teenuses.

## Enne avaldamist

- Vaata üle ja asenda kontseptsioonina märgitud näidisprojektid kinnitatud töödega.
- Kontrolli, kas `hello@priitlinnakivi.ee` on õige e-posti aadress.
- Lisa ainult kinnitatud projektide tulemused ja mõõdikud.
- Google Fonts laaditakse võimalusel välisest teenusest; fontide laadimata jäämisel kasutatakse süsteemseid varufonte.

Heli on vaikimisi väljas ning helinäide luuakse Web Audio API abil alles kasutaja nupuvajutusel. Portree asub kaustas `img/`.
